# 📊 Estudos de Análise de Dados com Python

## 📌 Sobre o repositório

Este repositório reúne notebooks desenvolvidos no **Google Colab** durante meus estudos de análise de dados com Python.

O objetivo é praticar conceitos de programação, manipulação e exploração de dados, visualização de informações e interpretação de resultados, desenvolvendo habilidades para atuar na área de **Análise de Dados e Analytics**.

## 🎯 Objetivos de aprendizagem

- Desenvolver habilidades em Python aplicadas à análise de dados.
- Aprender a importar, organizar e tratar conjuntos de dados.
- Identificar padrões, tendências e informações relevantes.
- Criar gráficos e visualizações para facilitar a interpretação dos dados.
- Praticar a análise exploratória de dados (EDA).
- Desenvolver o raciocínio analítico para transformar dados em informações úteis.

## 🛠️ Tecnologias e ferramentas

- **Python** — linguagem de programação.
- **Google Colab** — ambiente de desenvolvimento dos notebooks.
- **Pandas** — manipulação e análise de dados.
- **NumPy** — operações numéricas.
- **Matplotlib** — criação de gráficos.
- **Seaborn** — visualização e análise estatística.
- **GitHub** — versionamento e organização dos estudos.

As bibliotecas serão utilizadas conforme a necessidade de cada notebook.

## 📚 Conteúdo do repositório

Os notebooks serão adicionados conforme meu progresso nos estudos, podendo incluir:

| Tema | Conteúdo |
|---|---|
| Fundamentos de Python | Variáveis, estruturas de controle, listas e funções |
| Manipulação de dados | Leitura de arquivos CSV e Excel, filtros e ordenação |
| Limpeza de dados | Valores ausentes, duplicidades e inconsistências |
| Análise exploratória | Estatísticas descritivas, padrões e tendências |
| Visualização de dados | Gráficos de barras, linhas, histogramas e dispersão |
| Projetos práticos | Análises com conjuntos de dados reais ou fictícios |

## 🚀 Como utilizar

1. Explore os notebooks disponíveis neste repositório.
2. Abra o notebook desejado.
3. Clique no botão **Open in Colab**, quando disponível, ou faça o download do arquivo `.ipynb` e importe-o para o Google Colab.
4. Execute as células para acompanhar as análises.
5. Experimente modificar o código e desenvolver novas análises.

Alguns notebooks podem exigir o download de bases de dados ou a instalação de bibliotecas específicas. Essas instruções estarão descritas no próprio notebook, quando necessário, com os respectivos links.
